## SysSet

> System Setup

```
./sysset [-v[v]] [common|desktop|server]
```

## SysGet

> System Get software

```
install ./sysget /usr/local/bin/sysget

sysget <update|upgrade|search|install|list|remove|clean>
```

## SysSrv

> System Services

```
install ./syssrv /usr/local/bin/syssrv

syssrv <start|status|reload|stop>
```
